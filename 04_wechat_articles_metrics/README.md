# 04 — WeChat article metrics

**Slug:** `wechat.articles.metrics` (POST `/wechat/articles/metrics`)

Pass a public article URL. For richer metrics see `wechat.articles.metrics/pro` (`client.wechat.articles.metrics_pro`).

```bash
export XTREE_API_KEY=xt_live_...
python main.py "https://mp.weixin.qq.com/s/xxxxxxxx"
```
